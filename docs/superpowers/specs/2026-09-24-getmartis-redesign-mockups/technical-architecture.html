Arquitectura técnica do redesign

Preserva o investimento em React/Vite/MDX e acrescenta geração determinística, HTML pré-renderizado e contratos verificáveis.

1 · Sources of truth

martis-packageDocs, version, requirements, CHANGELOG and commit SHA.
CI reportsMachine-readable Pest and Vitest totals.
PlaygroundSeeded canonical product states and screenshots.
Official external sourcesPackagist stats and competitor documentation.

2 · Build-time pipelines

Content sync → MDXExisting sync becomes a mandatory release gate.
Release data → generated JSONNo version, test count or download number in JSX.
Comparison validatorChecks source URL, review date and required fields.
Product capturePlaywright produces the canonical media set and manifest.

3 · Static experience

Marketing routesHome, Product, Agencies, Compare and Changelog.
Documentation routesMDX pages, search index, task-based navigation.
Pre-rendered HTMLUnique metadata, canonical URL, Open Graph and JSON-LD per route.
Hydrated interactionsSearch, copy, tabs, media viewer and motion only where needed.

Request and render flow

Static HTML firstReadable content and SEO without waiting for JavaScript.
Route chunk hydratesReact attaches only the interactions for the current route.
Local generated dataStats and comparisons load from the deployed build, not remote APIs.
Progressive mediaResponsive images and clips load below the fold on demand.

Graceful at runtime

  • the page remains readable when JavaScript is delayed;
  • motion and video degrade to a poster image;
  • copy controls expose success via aria-live;
  • search failure links to navigation instead of a blank modal;
  • missing optional media never collapses the layout.

Fail loudly at build/release

  • missing generated metadata stops the build;
  • stale docs or comparison sources stop release preparation;
  • broken internal links or canonical routes fail CI;
  • missing screenshot manifest fails visual pages;
  • production smoke failure leaves the release incomplete and retryable.

Verification matrix

UnitGenerated data parsers, route metadata, comparison freshness and formatting.
ComponentNavigation, install command, comparison rows, theme switch and docs search states.
End-to-endKey visitor paths from Home → Compare/Agencies → Installation.
Visual regression375, 768, 1024 and 1440 px; docs in light and dark mode.
Accessibilityaxe, keyboard journeys, focus order, dialog focus return and reduced motion.
Release contractVersion/SHA match, content sync, capture manifest, dist checksum and production smoke.
Deliberate non-migration: no Astro or framework rewrite. React 18, Vite, TypeScript and MDX remain; a small server-render build entry pre-renders the known route catalogue and the browser hydrates it. This keeps the existing search/content investment while fixing SEO and first paint.
